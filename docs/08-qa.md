# 08 — QA report

Run on 23 Nov 2026 against the production build (`astro build` → `astro preview`), in a Linux sandbox with Google Chrome (headless) and Playwright 1.65. Every number below was measured here. Nothing is estimated.

## Automated tests: `npm test` (tests/site.spec.ts)
**32 passed, 2 skipped by design** (keyboard flow is desktop-only; the mobile menu is mobile-only), across two projects: *desktop* (Chrome 1440×900) and *mobile* (Pixel 7 emulation).

| Test | Covers |
|---|---|
| Renders each of 7 pages | HTTP 200, one `h1`, `noindex`, OG image, absolute canonical, **no horizontal overflow**, **no console/page errors** (store-hosted photos excluded; see below) |
| Internal links and assets | Every internal `href`/`src` across all pages returns < 400 |
| Store links | Every "Buy" on /aroma matches `https://globalaroma.me/product/<slug>/` |
| Shop | ≥ 60 distinct WooCommerce product links; price sort is ordered; no claim that orders reach anyone |
| Scent Map | Tap empty space → 4 nearest fragrances → detail dialog opens → Esc closes |
| Library | Shows 15, search "oud" narrows, "Sold online" gives 23, "Show all" gives 67 |
| Brief | Add from 3 pages → counter → items listed → needs pre-selected → validation blocks without contact → `mailto:info@globaldwc.com` and `wa.me/971555827212` carry space and shortlist → remove updates |
| Keyboard | First Tab reaches the skip link; dialog returns focus to its trigger |
| Mobile menu | Opens, `aria-expanded`, closes on Esc |
| Reduced motion | Hero stays a static SVG; no canvas |
| JavaScript off | Home text, 67 map links, 67 library cards all present; the brief shows contacts in `<noscript>` |

Also: `astro check` 0 errors; clean clone → `npm ci` → `npm run build` succeeds (10 pages incl. studio, plus 67 signature SVGs).

## Manual visual review
Every page screenshotted and reviewed at 1440 px and 390 px (full page), plus 375 px overflow checks. Issues found and fixed during review: map labels causing 25 px overflow; squeezed y-axis labels; faint thumbnails (switched to non-scaling strokes); busy division heroes (rebuilt as a framed split); chip squashing on mobile; very long mobile library (15-item preview); photo moment centring and caption; carousel slide 3 collision; small highlight icons; stacked reel labels; low-contrast labels.

## Social assets
26 frames rendered at exact sizes, plus 26 safe-zone proofs (`social/out/_safe-zones.png`) and a 12 s, 1080×1920, 30 fps H.264 reel. Each reviewed visually.

## Not verified here (honest gaps)
- **WebKit / Safari and Firefox:** Playwright's WebKit download is blocked in this sandbox. CI (`.github/workflows/ci.yml`) runs WebKit once the repository is on GitHub.
- **Real phones**, screen readers (VoiceOver/TalkBack) and Windows high-contrast mode: not tested.
- **Store photos** loading from globalaroma.me (blocked here).
- **Delivery** of brief emails/WhatsApp messages to the company. The links were verified, not the mailboxes.
- **WooCommerce checkout, order records and notifications:** out of scope and not accessed (doc 07).
- **Vercel Preview:** not deployed (no credentials in this environment).
