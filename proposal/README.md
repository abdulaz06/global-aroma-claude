# Proposal source

`Global Aroma - Digital Experience Proposal.pdf` is rendered from these slides with `npm run proposal` (writes the PDF into this folder; git-ignored). Twelve 1920×1080 pages with clickable links to https://global-aroma-website.vercel.app/. Images are in `img/` (`IMG:name.jpg` in the slides). The same slides are also kept as an editable online slide deck.

Owner-facing: no tool names, pricing, timelines or internal history belong in these slides.
